# Desafios-JS-DIO---Blip

🚀 Sobre os Desafios
Os exercícios simulam cenários reais de um desenvolvedor júnior em uma startup de chatbots, onde a padronização e a experiência do usuário são fundamentais.

1. Conversão de Mensagens para Caixa Alta
   Objetivo: Padronizar as mensagens automáticas convertendo todo o texto para letras maiúsculas, garantindo clareza na comunicação.

Entrada: Uma string (letras, números, espaços e pontuação).

Saída: A mesma string com todas as letras em maiúsculo.

Regra: Não utilizar bibliotecas externas.

2. Saudação Personalizada Multicanal
   Objetivo: Criar uma função flexível que receba o nome do cliente e o canal de atendimento para gerar uma saudação amigável e padronizada.

Padrão da Mensagem: "Ola, [nome do cliente]! Bem-vindo ao canal [nome do canal]."

Parâmetros: nomeDoCanal e nomeDoCliente.

Foco: Reutilização de código e uso de parâmetros.

3. Saudação Inteligente para Bots
   Objetivo: Simular o comportamento de um bot que identifica o canal de origem e responde com uma mensagem específica para aquele ecossistema.

Lógica de Resposta:

whatsapp → "Ola, este e o WhatsAppBot!"

telegram → "Ola, este e o TelegramBot!"

webchat → "Ola, este e o WebChatBot!"

Outros → "Canal nao suportado"

Foco: Estruturas condicionais e retorno único.
